PYTHON — Записка 2. Уровень 1 (условия if)
Соответствует 5 заданиям каталога fallback (см. docs/EDUCATION.md).

══════════════════════════════════════
КАК ПРОВЕРЯЮТ
══════════════════════════════════════
Нужна логика: переменные и if/else. Простой print готового ответа без условий не пройдёт.

══════════════════════════════════════
ЗАДАНИЕ 1 — x = 12, больше 10?
══════════════════════════════════════
x = 12
if x > 10:
	print("Большое")
else:
	print("Маленькое")
Ожидаемый вывод: Большое

══════════════════════════════════════
ЗАДАНИЕ 2 — чётность (x = 7)
══════════════════════════════════════
x = 7
if x % 2 == 0:
	print("Even")
else:
	print("Odd")
Ожидаемый вывод: Odd

══════════════════════════════════════
ЗАДАНИЕ 3 — строка Python
══════════════════════════════════════
s = "Python"
if s == "Python":
	print("Да")
else:
	print("Нет")
Ожидаемый вывод: Да

══════════════════════════════════════
ЗАДАНИЕ 4 — отрицательное число (x = -5)
══════════════════════════════════════
x = -5
if x < 0:
	print("Минус")
else:
	print("Плюс")
Ожидаемый вывод: Минус

══════════════════════════════════════
ЗАДАНИЕ 5 — делится на 3 (x = 9)
══════════════════════════════════════
x = 9
if x % 3 == 0:
	print("Div3")
else:
	print("No")
Ожидаемый вывод: Div3

══════════════════════════════════════
СОВЕТ
══════════════════════════════════════
Имя переменной (x, s) может совпадать с условием — важны значения и ветка if.
