PYTHON — Записка 3. Уровни 2–3 (циклы и списки)
Соответствует заданиям каталога fallback (см. docs/EDUCATION.md).
На уровнях 2–3 проверка через ИИ на сервере; ожидаемый вывод всё равно должен совпасть.

══════════════════════════════════════
УРОВЕНЬ 2 — циклы
══════════════════════════════════════

1) Список [1,2,3] — каждое число с новой строки:
for n in [1, 2, 3]:
	print(n)
→ 1\n2\n3

2) Сумма 1..5:
print(sum(range(1, 6)))
→ 15

3) Квадраты 1..3:
for i in range(1, 4):
	print(i * i)
→ 1\n4\n9

4) Список ['a','b','c']:
for ch in ['a', 'b', 'c']:
	print(ch)
→ a\nb\nc

5) Длина списка [10,20,30]:
print(len([10, 20, 30]))
→ 3

══════════════════════════════════════
УРОВЕНЬ 3 — списки и логика
══════════════════════════════════════

1) Сортировка [5,2,9,1]:
nums = [5, 2, 9, 1]
print(sorted(nums))
→ [1, 2, 5, 9]

2) Чётные из [1,2,3,4,5]:
for n in [1, 2, 3, 4, 5]:
	if n % 2 == 0:
		print(n)
→ 2\n4

3) Максимум в [3,7,2]:
print(max([3, 7, 2]))
→ 7

4) Минимум в [3,7,2]:
print(min([3, 7, 2]))
→ 2

5) Сумма [1,2,3,4]:
print(sum([1, 2, 3, 4]))
→ 10

══════════════════════════════════════
СОВЕТ
══════════════════════════════════════
Смотри ожидаемый вывод в терминале: пробелы в "[1, 2, 5, 9]" и переносы строк важны.
