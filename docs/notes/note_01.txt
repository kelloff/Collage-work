PYTHON — Записка 1. Уровень 0 (вывод и переменные)
Соответствует 5 заданиям каталога fallback (см. docs/EDUCATION.md).

══════════════════════════════════════
КАК ПРОВЕРЯЮТ (уровень 0–1)
══════════════════════════════════════
Терминал сравнивает твой ВЫВОД с ожидаемым текстом посимвольно.
На уровне 0 можно вывести ответ одним print("...") — это разрешено.

══════════════════════════════════════
ЗАДАНИЕ 1 — Hello, World!
══════════════════════════════════════
print("Hello, World!")
Ожидаемый вывод: Hello, World!

══════════════════════════════════════
ЗАДАНИЕ 2 — переменная Python
══════════════════════════════════════
lang = "Python"
print(lang)
Ожидаемый вывод: Python

══════════════════════════════════════
ЗАДАНИЕ 3 — число 20
══════════════════════════════════════
x = 20
print(x)
Ожидаемый вывод: 20

══════════════════════════════════════
ЗАДАНИЕ 4 — сложение 2 + 3
══════════════════════════════════════
print(2 + 3)
Ожидаемый вывод: 5

══════════════════════════════════════
ЗАДАНИЕ 5 — выражение 7*8
══════════════════════════════════════
print(7 * 8)
Ожидаемый вывод: 56
