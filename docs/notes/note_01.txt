PYTHON — Записка 1. Вывод, переменные, строки, списки и словари
(под задания уровня 0: один print = одна строка вывода, если в условии так сказано)

══════════════════════════════════════
КАК ПРОВЕРЯЮТ РЕШЕНИЕ
══════════════════════════════════════
Терминал сравнивает твой ВЫВОД программы с ОЖИДАЕМЫМ текстом.
• Должны совпасть символы, пробелы и ПЕРЕНОСЫ СТРОК (\n).
• Если в примере одна строка — обычно один print. Если несколько строк подряд — несколько print() или один print с \n.

══════════════════════════════════════
ВЫВОД НА ЭКРАН
══════════════════════════════════════
print(42)
print("Привет")
print('Привет,мир')          # строка без лишних пробелов, если так в задании

══════════════════════════════════════
ПЕРЕМЕННЫЕ
══════════════════════════════════════
x = 42
print(x)

name = "Alice"
age = 30

══════════════════════════════════════
СТРОКИ И КАВЫЧКИ
══════════════════════════════════════
# Текст в двойных или одинарных кавычках — это строка.
s = "Привет, Мир!"
print(s)

# Вывести ровно то, что просят (иногда без пробелов между словами):
print("Привет,мир")

══════════════════════════════════════
СПИСОК И ВЫВОД ЧИСЕЛ ЧЕРЕЗ ПРОБЕЛ
══════════════════════════════════════
# Числа от 1 до 5 одной строкой: "1 2 3 4 5"
nums = [1, 2, 3, 4, 5]
print(*nums)                 # звёздочка «распаковывает» в print через пробел

# Или так:
print(" ".join(str(n) for n in range(1, 6)))

══════════════════════════════════════
СЛОВАРЬ И ТЕКСТ ПО ШАБЛОНУ
══════════════════════════════════════
d = {"name": "Alice", "age": 30}
# Пример формата: Имя: Alice, Возраст: 30
print("Имя: " + d["name"] + ", Возраст: " + str(d["age"]))
# или f-строка:
print(f"Имя: {d['name']}, Возраст: {d['age']}")

══════════════════════════════════════
СОВЕТ
══════════════════════════════════════
Сначала добейся правильного текста в уме, потом набирай код. Не добавляй лишних print("готово") — только то, что просит формулировка.
