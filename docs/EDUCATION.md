# Учебный план игры (каталог fallback)

Один канонический набор из **20 заданий** (уровни сложности Python **0–3**, по **5** на уровень).

| Где живёт каталог | Файл |
|-------------------|------|
| Источник правды | `beck/tasks_fallback_catalog.py` |
| Сервер `source=fallback` | `generate_service.fallback_generate_tasks()` |
| Офлайн / 503 в Godot | `db/task_data.gd` (синх: `python beck/sync_task_data_gd.py`) |
| Подсказки в игре | `docs/notes/note_01.txt` … `note_03.txt`, журнал **B** |

Ollama может выдавать **другие** формулировки (`source=pool` / `ollama`). Для стабильного прохождения на слабом сервере включай `GENERATE_FALLBACK_ON_MISS=1` или держи пул, собранный из того же каталога.

**Вне программы:** задания про дату, время, `datetime`, календарь и «текущую дату» **не входят** в курс. Генератор их не создаёт и отбрасывает; в каталоге fallback их нет.

---

## Уровни сложности (task.level)

| level | Тема | Проверка в терминале | Записка |
|-------|------|----------------------|---------|
| **0** | print, переменные, арифметика | Локально (CodeRunner) | note_01 |
| **1** | if / else | Локально | note_02 |
| **2** | циклы, списки | ИИ `/check_task` | note_03 |
| **3** | списки, min/max/sort/sum | ИИ `/check_task` | note_03 |

`computer.level` на карте должен совпадать с `task.level` пула (см. level_1.tscn).
