The Last Code — системные требования
====================================

Windows x64, Godot 4.6. Игра поддерживает офлайн-режим с ограничениями.

ОБЯЗАТЕЛЬНО
----------
  • Windows 10 или 11 (64-bit)
  • Python 3.8+ в PATH — для проверки кода в терминале
    (py -3 или python; галочка «Add to PATH» при установке)
  • Интернет — желателен, но не обязателен:
    — без сети: встроенный набор заданий и локальная проверка
    — с сетью: свежие задания с kellofff.me и ИИ-проверка на 2–3

МИНИМАЛЬНЫЕ
-----------
  • CPU: 2 ядра, 2.0 ГГц
  • ОЗУ: 4 ГБ
  • GPU: Vulkan 1.2+
  • Экран: от 1280×720
  • Диск: ~110 МБ + сохранения в %APPDATA%\Godot\...

ОФЛАЙН-РЕЖИМ (без интернета)
----------------------------
  • «Новая игра» — встроенные задания из игры (не с сервера).
  • Терминал — проверка на вашем Python (сравнение stdout).
  • Задания 2–3: без ИИ на сервере, только точное совпадение вывода.
  • «Продолжить» — работает с локального сохранения.

С СЕТЬЮ
-------
  • Задания с сервера, проверка 2–3 через kellofff.me/check_task.

НЕ НУЖНО
--------
  • beck/, Ollama, backend, Godot Editor

Тест офлайн: переменная COLLAGE_OFFLINE=1 перед запуском exe.

Версия: 1.0.0
