The Last Code
=============

Запуск: TheLastCode.exe (из папки установки).

Управление:
  WASD — движение
  E — взаимодействие (компьютер, дверь, рычаг)
  Esc — меню паузы

Перед первой игрой:
  1. Python 3.8+ в PATH (нужен для проверки кода в терминале).
  2. Интернет желателен: свежие задания и ИИ на уровнях 2–3.
     Без сети игра тоже работает (встроенные задания, проверка на ПК).

Подробные требования: SYSTEM_REQUIREMENTS.txt (в папке игры).

Сохранения и черновики кода — в %APPDATA%\Godot\app_userdata\...
